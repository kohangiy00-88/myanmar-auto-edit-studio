Myanmar TTS သည် API/provider ၏ Burmese language support နဲ့ အသံအရည်အသွေးအပေါ် မူတည်ပါတယ်။

④ လုပ်ဆောင်ပုံ

1. Backend API ကို Run ပါ။
2. Video file ကိုရွေးပါ။
3. Auto Transcribe ကိုနှိပ်ပါ။
4. စာတန်းအချိန်နဲ့ စာသားကို စစ်ဆေးပါ။
5. Render MP4 ကိုနှိပ်ပြီး Output သိမ်းပါ။

စာတန်းကို တစ်ကြောင်းချင်း ထုတ်ပေးရန် phrase wrapping ပါဝင်သည်။ ရုပ်ရှင် recap အတွက် ပြန်ဆိုထားသော စာသားကို မူရင်းနဲ့ ပြန်စစ်ပါ။
